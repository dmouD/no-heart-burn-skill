## 安装：放对位置，再开口

下载完了，再放进项目；目录放好了，再调用。宁可慢一点，也不能坏了规矩。

1. 先下载并解压本仓库，或使用本仓库的实际地址 `clone` 到本地。下载完了，再找到 `no-heart-burn-skill/`。
2. 目录找到了，再复制。将整个 `no-heart-burn-skill/` 文件夹放进目标项目的 `.agents/skills/`。文件要齐，目录要对；下面的两个路径先换成自己的目录：

   ```bash
   skill_repo="/path/to/downloaded-repo"
   target_project="/path/to/your-project"
   mkdir -p "$target_project/.agents/skills"
   cp -R "$skill_repo/no-heart-burn-skill" "$target_project/.agents/skills/"
   ```
3. 复制完了，再打开 Codex。入口核对为 `.agents/skills/no-heart-burn-skill/SKILL.md`，在目标项目中调用技能；技能列表里没看到怎么办？先重启 Codex。

规矩从哪看？项目技能目录与调用方式，见 [OpenAI 官方技能说明](https://learn.chatgpt.com/docs/build-skills)。

